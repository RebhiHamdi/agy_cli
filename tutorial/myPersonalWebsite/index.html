chaiserelante

Wheelchair Security & 360° Multi-Sensor Obstacle Avoidance System

A high-reliability active security and collision prevention system engineered for powered wheelchairs. Utilizes a Nordic nRF52 SoC connected to an I2C multiplexer (TCA9548A) controlling an array of 7 ultrasonic distance sensors arranged in a spatial perimeter.

TARGET MCU Nordic nRF52 (ARM Cortex-M4)
PERIPHERALS I2C MUX + 7x Ultrasonic Transducers
ENVIRONMENT Zephyr RTOS / Embedded C
RESPONSE TIME < 15 ms Emergency Trigger
• Multiplexed I2C Bus: Dynamically sweeps 7 ultrasonic transceivers without address collision in < 45ms.
• Deterministic Safety Loop: Real-time distance evaluation with multi-zone emergency slowdown and automatic braking.

rinPen

Digital Air-Writing Smart Stylus & 6-DOF Spatial Motion Tracker

An ultra-compact spatial air-writing instrument and motion-sensing stylus based on the Panasonic PAN1780 module (Nordic nRF52840). Captures handwriting kinematics in 3D space using 6-axis inertial measurement sensors and streams high-fidelity stroke vectors over custom BLE GATT services.

WIRELESS MODULE Panasonic PAN1780 (nRF52840)
SENSORS 6-DOF IMU (Accel + Gyro)
CONNECTIVITY BLE 5.0 Custom GATT / HID
SAMPLE RATE 100 Hz Streamed @ < 8mA
• On-Device Sensor Fusion: Lightweight orientation filter running on ARM Cortex-M4F with hardware FPU acceleration.
• Ultra-Low Power Architecture: Motion-activated interrupt wake-up and sub-microamp deep sleep state.
